# Doors v3 — Bedrock 26.60 working fix

Download the addon: [Doors-26.60-working-fix.mcaddon](https://github.com/Justin-Developer01/doors-mod-fix/releases/download/v1.3.2/Doors-26.60-working-fix.mcaddon)

## Install

1. Use Minecraft Bedrock **26.60**.
2. Import `Doors-26.60-working-fix.mcaddon`.
3. Activate the **resource pack**, then the **behavior pack**.
4. Turn off the older CurseForge Doors pack so it does not override this one.
5. Leave **Beta APIs** off.

## What works

A crucifix removes A-60, A-90, and A-120, and now banishes Rush and Ambush. Keys, levers, the hammer breaker, elevators, and Jeff's shop work. The holy hand grenade and the shield potion work. The behavior pack loads the script API on Bedrock 26.60.
